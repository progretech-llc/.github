# ProgreTech LLC

**Practical engineering for complicated systems.**

ProgreTech is the independent software engineering practice and public workshop of Ed. Abdiel Rodriguez. We build and share practical software, automation, applied AI, and reliability tools—along with experiments and lessons from making them useful.

[Explore ProgreTech](https://progretech.com) · [Featured projects](https://progretech.com/featured-projects/) · [Contact](https://progretech.com/contact/)

## What we work on

- Software engineering and developer tools
- Process and browser automation
- Applied AI and document/OCR workflows
- Site reliability engineering and operational reliability
- Risk, dependency, and change analysis
- Enterprise integration and data interfaces
- Learning tools and digital preservation
